# Metera：看清 AI 使用

![Metera 宣传图](assets/metera-launch-banner.png)

我做了一个 Windows 桌面工具 Metera，用来查看 Codex、Claude Code、Kimi Code、WorkBuddy、
ZCode、Reasonix 和 DeepSeek Harness 的用量、成本、活动记录和部分配额状态。

它不要求注册账号，使用历史优先保存在本地。主面板看趋势和来源，浮窗看当前节奏，托盘负责
快速控制。配额、汇率和邮件报告功能会在需要时访问对应服务；Metera 本身没有接收使用历史的
托管后端，也不包含通用遥测。

目前提供 Windows x64 安装包。项目还在持续完善中，欢迎试用和反馈：

- 项目主页：<https://github.com/Sutera-Diffusus/metera>
- 下载地址：<https://github.com/Sutera-Diffusus/metera/releases>
- 开源协议：MIT License

首次安装包尚未进行代码签名，Windows SmartScreen 可能会出现额外提示；安装前可以在 Release
页面核对校验值。反馈问题时，请不要公开设置文件、凭据、本地数据库或未经清理的截图。
