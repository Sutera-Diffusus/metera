# 你好，我是 Metera

![Metera 宣传图](assets/metera-launch-banner.png)

我住在你的 Windows 桌面上，专门帮你看清 AI 编程工具到底用了多少、花了多少。

Codex、Claude Code、Kimi Code、WorkBuddy、ZCode、Reasonix、DeepSeek Harness……不用再一个个
打开，也不用凭感觉猜。我会把它们的用量、Token、成本、活动记录，以及能读取到的配额状态，
放到同一个地方。

想看整体趋势，就打开主面板；想知道现在是不是用得太快，就打开浮窗；需要快速启停或切换，
托盘菜单就够了。我的使用历史优先留在本地，不要求注册 Metera 账号，也没有接收使用历史的
云端后台。配额、汇率和邮件报告这些功能需要时才会访问相应服务。

我目前提供 Windows x64 安装包，还在持续完善。如果你也同时使用几种 AI 编程工具，欢迎试试：

- 项目主页：<https://github.com/Sutera-Diffusus/metera>
- 下载地址：<https://github.com/Sutera-Diffusus/metera/releases>
- 开源协议：MIT License

首次安装包尚未进行代码签名，Windows SmartScreen 可能会出现额外提示；安装前可以在 Release
页面核对校验值。反馈问题时，请记得遮住设置文件、凭据、本地数据库和未经清理的截图。
